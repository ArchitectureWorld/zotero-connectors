Zotero 外部脚本保存功能——小白测试说明
==========================================

你不需要安装 Python、Node.js、WSL，也不需要输入命令。

准备工作
--------
1. Windows 10 或 Windows 11。
2. 已安装 Chrome。
3. 已安装并打开 Zotero 桌面版。
4. 测试时先关闭 Chrome 商店中的官方 Zotero Connector，避免出现两个 Zotero 图标。

安装步骤
--------
第一步：双击“1-安装本地助手.bat”
看到“本地助手安装完成”即可。

第二步：双击“2-加载浏览器插件.bat”
浏览器会打开扩展管理页面，同时打开“浏览器插件”文件夹。
在 Chrome 中：
1. 打开右上角“开发者模式”；
2. 点击“加载已解压的扩展程序”；
3. 选择“浏览器插件”文件夹。

第三步：双击“3-测试连接.bat”
看到“连接成功”即可。

保存测试
--------
1. 在 Chrome 打开一篇论文详情页；
2. 保持 Zotero 桌面版处于打开状态；
3. 双击“4-保存当前网页.bat”；
4. 到 Zotero 中确认文献是否出现。

然后再测试两次：
- 切换到其他软件，让 Chrome 位于后台，再双击“4-保存当前网页.bat”；
- 把 Chrome 最小化，再双击“4-保存当前网页.bat”。

三个场景都能保存，并且 Chrome 没有被强制切到前台，就说明功能通过。

卸载
----
双击“5-卸载.bat”，然后在 Chrome 扩展管理页面中手动删除测试插件。

注意
----
“保存命令已发送”表示插件已经开始执行官方 Zotero 保存动作。
最终是否保存成功，请以 Zotero 文献库中是否出现条目为准。
