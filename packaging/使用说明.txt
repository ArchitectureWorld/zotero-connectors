Zotero 外部脚本保存功能——安装与测试说明（协议 V3）
===================================================

你不需要安装 Python、Node.js、WSL，也不需要输入命令。

准备工作
--------
1. Windows 10 或 Windows 11。
2. 已安装 Chrome。
3. 已安装并打开 Zotero 桌面版。
4. 安装时先关闭 Chrome 商店中的官方 Zotero Connector，避免出现两个 Zotero 图标。

安装步骤
--------
第一步：双击“1-安装本地助手.bat”
看到“本地助手安装完成”即可。

第二步：双击“2-加载浏览器插件.bat”
程序会尝试打开扩展管理页面和“浏览器插件”文件夹。
如果 Chrome 没有自动打开，请自行在地址栏输入：chrome://extensions

在 Chrome 中：
1. 打开右上角“开发者模式”；
2. 点击“加载已解压的扩展程序”；
3. 选择“浏览器插件”文件夹。

第三步：双击“3-测试连接.bat”
必须看到：
“连接成功：浏览器插件已支持精确网页保存与指定集合归档（协议 V3）。”

如果提示“检测到旧版插件”，请在 chrome://extensions 中删除旧的测试插件，再重新加载当前包的“浏览器插件”文件夹。

普通保存测试
------------
1. 在 Chrome 打开一篇论文详情页；
2. 保持 Zotero 桌面版处于打开状态；
3. 双击“4-保存当前网页.bat”；
4. 到 Zotero 中确认文献是否出现。

然后再测试两次：
- 切换到其他软件，让 Chrome 位于后台，再双击“4-保存当前网页.bat”；
- 把 Chrome 最小化，再双击“4-保存当前网页.bat”。

三个场景都能保存，并且 Chrome 没有被强制切到前台，就说明基础功能通过。

指定集合归档
------------
1. 先在 Zotero 桌面端手动创建目标集合；
2. 自动化调用保存命令时传入目标集合的完整路径；
3. 路径从文库下的第一级集合开始，各级用 / 分隔。

命令示例：

zotero_script_trigger_cli.exe save-url --url "https://example.org/paper" --collection "自动文献收集/建筑数字化技术/第一轮广义收集"

默认保存到个人文库 L1。目标集合不存在、路径不完整或页面不支持保存会话时，程序会直接报错，不会静默退回“我的文库”。

Agent / Skill 功能
------------------
当前版本额外支持：
- 列出可保存的浏览器标签页；
- 根据标签页 ID 精确保存；
- 根据完整网页 URL 精确保存；
- 根据 URL 或标题片段查找，但多个网页同时匹配时会拒绝执行；
- 将文献归入 Zotero 中已经存在的指定集合。

CNKI Zotero Skill 使用完整的代理详情页 URL 定位目标，不依赖当前活动页面，也不模拟快捷键。

卸载
----
双击“5-卸载.bat”，然后在 Chrome 扩展管理页面中手动删除测试插件。

注意
----
普通保存中的 triggered=true，只表示插件已经开始执行官方 Zotero 保存动作，最终结果仍应检查 Zotero 数据库。
指定集合保存中的 collectionApplied=true，表示插件已经完成本次保存并向同一保存会话执行了集合归档命令。
