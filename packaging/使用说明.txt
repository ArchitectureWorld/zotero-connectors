Zotero 外部脚本保存功能——一键部署说明（协议 V3）
=================================================

你不需要安装 Python、Node.js、WSL，也不需要手工加载浏览器插件。

准备工作
--------
1. Windows 10 或 Windows 11。
2. 已安装并打开 Zotero 桌面版。
3. 安装包需要完整解压后再运行，不能直接在 ZIP 预览窗口中双击。

一键安装
--------
只需要双击：

0-一键安装并启动.bat

程序会自动完成：
- 安装本地 Native Messaging 助手；
- 注册 Chrome / Edge 本地通信接口；
- 将 Zotero Connector 复制到固定安装目录；
- 安装包内置的专用自动化浏览器；
- 创建桌面和开始菜单入口“Zotero 自动化浏览器”；
- 启动自动化浏览器；
- 检查协议 V3、精确 URL 保存和指定集合归档能力。

看到以下内容即表示部署闭环完成：

一键部署完成。
协议版本：V3
指定集合归档：已启用

安装目录
--------
所有文件安装到：

%LOCALAPPDATA%\ZoteroScriptTrigger

自动化浏览器使用独立配置目录：

%LOCALAPPDATA%\ZoteroScriptTrigger\browser-profile

网站登录状态会保存在该目录。首次使用知网、学校代理等需要登录的网站时，只需要在“Zotero 自动化浏览器”中登录一次，之后继续复用该登录状态。

日常使用
--------
桌面双击“Zotero 自动化浏览器”，在其中打开需要保存的论文网页。

普通保存测试：
1. 打开一篇论文详情页；
2. 保持 Zotero 桌面版处于打开状态；
3. 双击“4-保存当前网页.bat”；
4. 到 Zotero 中确认文献是否出现。

自动化程序也可以直接调用：

%LOCALAPPDATA%\ZoteroScriptTrigger\zotero_script_trigger_cli.exe

指定集合归档
------------
1. 先在 Zotero 桌面端手动创建目标集合；
2. 自动化调用保存命令时传入目标集合的完整路径；
3. 路径从文库下的第一级集合开始，各级用 / 分隔。

命令示例：

zotero_script_trigger_cli.exe save-url --url "https://example.org/paper" --collection "自动文献收集/建筑数字化技术/第一轮广义收集"

默认文库目标为 L1。目标集合不存在、路径不完整或页面不支持保存会话时，程序会直接报错，不会静默退回“我的文库”。

旧式手动安装入口
----------------
以下入口仅作为故障排查和开发备用，不是日常安装路径：
- 1-安装本地助手.bat
- 2-加载浏览器插件.bat
- 3-测试连接.bat

一键部署正常时，不需要运行这三个文件。

Agent / Skill 功能
------------------
当前版本支持：
- 列出可保存的浏览器标签页；
- 根据标签页 ID 精确保存；
- 根据完整网页 URL 精确保存；
- 根据 URL 或标题片段查找，但多个网页同时匹配时拒绝执行；
- 将文献归入 Zotero 中已经存在的指定集合；
- Chrome 位于后台或最小化时继续执行，不模拟键盘或鼠标。

卸载
----
双击“5-卸载.bat”。程序会关闭专用自动化浏览器，并删除本地助手、浏览器、插件、独立浏览器配置和快捷方式。

注意
----
普通保存中的 triggered=true，只表示插件已经开始执行官方 Zotero 保存动作，最终结果仍应检查 Zotero 数据库。
指定集合保存中的 collectionApplied=true，表示插件已经完成本次保存并向同一保存会话执行了集合归档命令。
